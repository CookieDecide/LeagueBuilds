# Privacy Policy

Last updated: 2026-04-04

This Privacy Policy explains how LeagueBuilds handles information for:
- the desktop client (`LeagueBuilds_tauri_client`), and
- the hosted backend service (`LeagueBuilds_server`) when you use a public LeagueBuilds endpoint.

## 1. What We Collect

When the backend API is used, the server may process and log:
- IP address of the requester
- Request timestamp
- Requested champion and position
- A summoner header value sent by the client
- Basic service diagnostics and error logs

The desktop client stores local settings on your device, such as:
- configured server URL
- import preferences
- flash-key preference
- rune option preference

## 2. How Information Is Used

Information is used to:
- return build/rune/item recommendations
- operate, maintain, and debug the service
- monitor abuse and improve reliability

LeagueBuilds is not designed to collect sensitive personal data.

## 3. Data Sharing

LeagueBuilds does not sell personal data.

Data may be shared only when required to:
- operate infrastructure and security controls
- comply with legal obligations
- protect the service or users from abuse

## 4. Third-Party Services

LeagueBuilds may rely on third-party services and data sources, including:
- GitHub (source code, releases, issue tracking)
- Riot Data Dragon endpoints (game metadata/assets)
- Hosting/network providers for the backend service

Those services have their own privacy policies.

## 5. Data Retention

Operational logs are retained only as needed for service operation, diagnostics, and security.
Retention periods may vary based on operational needs.

## 6. Security

Reasonable technical and organizational measures are used to protect service data, but no system can be guaranteed 100% secure.

## 7. Your Choices

You can also choose to self-host the backend and control logs directly.

## 8. Open-Source Project Context

LeagueBuilds is an open-source project. Code and behavior are publicly auditable in this repository:
- https://github.com/CookieDecide/LeagueBuilds

## 9. Contact

For privacy questions or requests, open an issue in the repository:
- https://github.com/CookieDecide/LeagueBuilds/issues

## 10. Changes to This Policy

This policy may be updated from time to time. Updates will be published in this file with a revised "Last updated" date.
